# DDHSV2
First, images were resized, converted to three channels, normalized, and augmented. Second, Swin Transformer V2 extracted hierarchical morphology and texture features. Finally, pooled features were classified into three-class or binary DDH categories and evaluated using accuracy, sensitivity, specificity, F1-score, and AUC.
